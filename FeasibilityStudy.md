# OPEN-SOURCE FEASIBILITY STUDY

## Traditional Indian Puppet Show Application

### 1. Introduction

This feasibility study evaluates whether the Traditional Indian Puppet Show application can be developed and maintained using open-source software, frameworks, libraries and AI models.

### 2. Open-Source Technologies Used

| Component        | Technology                  |
| ---------------- | --------------------------- |
| Frontend         | HTML, CSS, JavaScript       |
| Backend          | Python, FastAPI             |
| AI Model         | Qwen2.5                     |
| Animation        | HTML5 Canvas, JavaScript    |
| Text-to-Speech   | Browser SpeechSynthesis API |
| Video Processing | FFmpeg                      |
| Version Control  | Git                         |
| Code Hosting     | GitHub                      |

### 3. Open-Source Requirements

- The project's source code must be publicly available through GitHub.
- Project documentation, including SRS, feasibility study and project constraints, must be maintained in the repository.
- Open-source frameworks, libraries and AI models should be prioritised.
- Third-party libraries, models, assets and datasets must comply with their respective licences.
- External services and dependencies must be clearly documented.
- API keys, passwords and confidential credentials must never be committed to the public repository.
- Git should be used to track development and contributions.
- Setup instructions should be provided so other developers can run and contribute to the project.

### 4. AI Model and Licensing Considerations

The project uses Qwen2.5 for AI-based story understanding and character identification. Qwen2.5 is an openly available model family with different model variants and licensing conditions.

Most standard Qwen2.5 variants use the Apache 2.0 licence, while the 3B and 72B variants have different licences. The exact model variant used in the project must be checked and its licence requirements followed.

### 5. Open-Source Feasibility Assessment

The project is feasible with an open-source foundation because its frontend, backend, animation, version control and video-processing components can use open-source technologies. Qwen2.5 provides an option for AI-based story analysis without depending on a proprietary model API.

The project must maintain proper attribution, licence compliance and documentation for all external dependencies.

### 6. Conclusion

The Traditional Indian Puppet Show application is feasible to develop using open-source technologies. Using Qwen2.5 for story analysis and open-source development tools supports transparency, accessibility, collaboration and future maintenance.
